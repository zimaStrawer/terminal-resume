# ZHANG Terminal Resume

在终端中打开一份交互式中文简历。需要 Node.js 18 或更新版本；访客电脑无需安装 Go，也无需访问 SSH 服务器。

```bash
npx -y zhang-terminal-resume
```

这是独立的本地命令行程序。首次运行时 npm 会下载程序，随后它在当前终端中启动。输入 `/help` 查看命令，`/projects` 查看项目，按 `Ctrl+C` 退出。

macOS、Linux、Windows 的 ARM64 和 x64 均包含预编译程序。项目源码、内容与构建说明位于上游 `terminal-resume` 项目。

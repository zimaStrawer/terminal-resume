ZHANG Terminal Resume · 界面预览

由真实运行的二进制 + pty 原始字节流还原（xterm.js），不是手绘稿。

  • 终端底色 #0D0D0D —— 通过 OSC 11 写入终端，整块画布都吃这个颜色。
  • 输入框 #201E1E 实心底，左右各一条主题色实心竖条 #16B8F3，始终钉在屏幕底部。竖条由格子背景色整格铺满画成，所以必然贴边、等高、连续无缝。靠字形墨迹画不出这个效果：方块字符 ▏/▕ 的墨迹高度由字体决定、会被切成几截；box-drawing 的 │（U+2502）为了让相邻行的线衔接，墨迹比格还高，会从框底漏出一截、在页面底色上显形。格内另留一个不可见的占位字形 ǀ（U+01C0，前景色 = 背景色）供光标定位与测试探针认框行。框内只有一行输入区，上下各一行内边距让它垂直居中；空态显示占位文案 随便聊聊，或按 "/" 唤出快捷命令（窄于 62 列时换成短句 按 "/" 唤出快捷命令）。
  • 提示字符是动画的 输入框里那个字符照搬网站模块标题的光标（AsciiTitle.astro）：闪烁 10 步 ×300ms → 停 560ms → 乱序 16 帧 ×64ms（字符集 x > / & - ~ ^ =）→ 停 720ms 循环，基字符是 ›。每一帧都只占 1 列，且暗态用空格填充，所以输入框整行宽度恒定、字位置不抖。快照只抓到循环中的某一帧，故各卡片里这个字符会不一样。
  • 框内不再重复快捷键提示 旧版那行 / shortcuts ctrl+p commands ctrl+c exit 已删除，提示统一由占位文案承担；输入框下方那一行也只在有通知（notices）时才出字。
  • 下拉框 不设背景色（直接落在终端底色上），未选中项灰色 #94A3B8，选中项主题色 #16B8F3。
  • 快捷菜单 / 唤出，四条固定文案（skills / resume / log / personal），永远落在输入框正上方，不遮 logo。
  • 收尾文案 跟在 logo 下方：一句致谢 + 一句邀请 + 一行主题色标语 Design Without Boundaries。空首页时它在 logo 与输入框之间，有了回答就和 logo 一起被顶上去、最终离屏。
  • 自由问答是真实 AI 输入不以 / 开头的文本会打到作品集站的 /api/chat（Cloudflare Pages Function），回答按 SSE 逐片回来。终端二进制里没有任何密钥，它只负责转发；密钥留在站点侧的环境变量里。默认地址取简历里的 profile.website（AI 和简历同一个站点），--api 可覆盖、--api off 可关闭。上文「对话」那组就是这条链路——后端用 scripts/chat-stub.py 这个确定性桩，回答固定，所以预览可复现、不碰网络。
  • 回答流式打印 逐字显现，未打印到的位置留空，整页行结构不跳动。网络快慢与打字速度是解耦的：网络只负责把整段变长，打字机负责追上去，所以慢网络下也不会先卡住再一次蹦一大段。
  • 长回答按内容宽度折行 真实 AI 回答通常是一整条不含任何换行的长句，必须折行显示。旧版对助手回答只做单行截断，实测一条 168 字的回答只显示出前 54 字、后面整段被静默丢掉（斜杠命令的本地回答自带换行，所以这个 bug 一直没暴露）。
  • 对话流 旧回答按顺序累积在下方，越攒越多就把收尾文案和 logo 一路顶出屏幕；输入框始终钉在底部。Esc 可中断正在生成的回答，已收到的部分会保留。
  • 简历未就绪时给进度占位 /resume 的 RESUME 一栏：profile.resume_url 为空时渲染「等待简历下载中」+ 一条 30 格进度条，而不是给一个打不开的链接（模板里原本是一条不存在的域名）。进度条只用 █ 与空格，刻意避开 ░▒▓、▏▎▍ 这些 East Asian Width = Ambiguous 的字形——它们在偏好 CJK 字体的终端里会被排成两列，把整行挤歪。填上真实 PDF 地址后自动变回可点击的下载链接，不用改代码。
  • LOGO SI 银灰 #A6AEBB + ZHOU 近白 #FFFFFF。
